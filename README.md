# GRASS GIS Scripts — Maximum-Likelihood Classification of Landsat TM over the Tokyo Area, Japan

GRASS GIS shell scripts used to produce the figures in the peer-reviewed article by Polina Lemenkova. The scripts perform supervised land-cover classification of Landsat TM images of the Tokyo area, Japan (2001, 2006, 2011) using maximum-likelihood discriminant analysis.

**Published in:** *Geodetski glasnik* **2020**, *51*, 5–25
**DOI:** https://doi.org/10.58817/2233-1786.2020.54.51.5
**Journal (open access):** https://glasnik.suggsbih.ba/glasnik/51/documents/GG51_Lemenkova.pdf
**figshare:** https://doi.org/10.6084/m9.figshare.13507761
**HAL:** https://hal.science/hal-03091835
**Zenodo:** https://doi.org/10.5281/zenodo.4407110
**SSRN:** https://ssrn.com/abstract=3758121

## Contents
GRASS GIS shell scripts for import and processing of Landsat TM imagery, generation of training signatures (i.class) and supervised classification by maximum-likelihood discriminant analysis (i.maxlik), with cartographic display, for the years 2001, 2006 and 2011.
